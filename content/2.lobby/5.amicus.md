**Amicus** is Inquest's personal discord bot developed by [carrion](https://www.torn.com/profiles.php?XID=588903) with the purpose to make life easy for every inquest's member. Every inquest member is free to use the bot on discord.

##

### How to use the Amicus bot

Use `/` when typing message to activate amicus and display available command. Choose from any commands listed below in the table and use them on discord.

![Amicus Panel](/images/amicus/amicusPanel.png)

### Amicus Commands

| Category   | Command                      | Description                                  |
| ---------- | ---------------------------- | -------------------------------------------- |
| ⚔️ War     | `/war_easy_target`           | Get 5 low-stat targets                       |
| ⚔️ War     | `/war_hosp_status`           | Check enemy hospital times                   |
| ⚔️ War     | `/war_flight_tracker`        | Check enemy landing times (Work in Progress) |
| ⚔️ War     | `/war_revive_status`         | Find revivable enemies                       |
| 🛡️ Faction | `/faction_hosp_status`       | Check faction member hospital times          |
| 🛡️ Faction | `/faction_revive_status`     | Find revivable allies                        |
| 👤 Player  | `/player_flight_tracker_add` | Add a player to the flight tracker           |
| 👤 Player  | `/player_flight_tracker_del` | Remove a player from the flight tracker      |
| 🔑 Keys    | `/amicus_add_key`            | Contribute an API key                        |
| 🔑 Keys    | `/amicus_remove_key`         | Remove your key                              |

### Help Amicus Improve

::code-collapse

```md [How to Add Amicus Key.md]
Access [account settings](https://www.torn.com/preferences.php#tab=api) > API Keys > Create New Key > Give key a name > Choose Limited > Click Add

Copy the API key > In any InQuest channel begin typing /amicus_add_key > you will see the command appear > Click the command > Paste you API key in.

The bot will check that the key is Limited, and return that the key has been accepted.
```

::

::code-collapse

```md [How to Remove Amicus Key.md]
You can remove your key at anytime by using the command: /amicus_remove_key
You'll receive a message confirming the key has been removed.
```

::
